# LinguaFlow — 复习队列业务规则（SRS）

> 本文档为 LinguaFlow（React Native + SQLite，无后端，B1→B2 职场技术人英语学习 App）的**核心留存引擎**规范。
> 描述复习队列的算法选型、数据结构、调度算法、各板块接入方式、UI 流程与验收标准。
> 供 AI（Cursor / Claude / Copilot）照此生成 `SRSService.ts` 及相关组件代码。

---

## 一、算法选型

| 方案 | 复杂度 | 效果 | 推荐 |
|------|--------|------|------|
| 固定间隔（1/3/7/14/30 天） | 低 | 一般 | ⭐⭐ |
| SM-2（Anki 经典） | 中 | 好 | ⭐⭐⭐⭐ |
| FSRS（Free Spaced Repetition Scheduler） | 高 | 最好 | ⭐⭐⭐⭐⭐ 最终目标 |
| **简化版 FSRS** | 中 | 接近 Anki | ⭐⭐⭐⭐⭐ **MVP 采用** |

### 决策

- **MVP 用简化版 FSRS**：核心逻辑 80 行搞定，效果接近 Anki
- **V2 升级到完整 FSRS**：400+ 行数学计算 + 参数拟合，MVP 没必要
- 核心机制：每次答题记录 `rating`（1=again / 2=hard / 3=good / 4=easy），根据 rating 计算下一次复习间隔
- 间隔 = `base_interval × difficulty × stability`
- `difficulty` 和 `stability` 随每次答题动态调整

## 二、数据结构

### 2.1 复习卡片表 `srs_cards`

```sql
-- 核心 SRS 表（每个"学习项"一条记录）
CREATE TABLE IF NOT EXISTS srs_cards (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  item_type TEXT NOT NULL,        -- 'vocab' / 'grammar' / 'sentence' / 'collocation'
  item_id TEXT NOT NULL,          -- 对应种子数据的 ID

  -- FSRS 简化参数
  difficulty REAL NOT NULL DEFAULT 5.0,    -- 1-10，越高越难记
  stability REAL NOT NULL DEFAULT 1.0,     -- 记忆稳定性（天）
  retrievability REAL DEFAULT 1.0,         -- 当前可提取概率

  -- 调度
  state TEXT NOT NULL DEFAULT 'new',       -- 'new' / 'learning' / 'review' / 'relearning'
  step INTEGER DEFAULT 0,                  -- learning 阶段步数
  interval_days INTEGER DEFAULT 0,         -- 当前间隔（天）
  due_date DATETIME NOT NULL,              -- 下次复习时间
  last_reviewed_at DATETIME,

  -- 统计
  review_count INTEGER DEFAULT 0,
  lapse_count INTEGER DEFAULT 0,           -- 遗忘次数
  total_time_spent INTEGER DEFAULT 0,      -- 累计学习时间（秒）

  created_at DATETIME NOT NULL,
  updated_at DATETIME NOT NULL,

  UNIQUE(user_id, item_type, item_id),
  FOREIGN KEY (user_id) REFERENCES user_profile(user_id)
);
```

### 2.2 复习流水表 `srs_reviews`

```sql
CREATE TABLE IF NOT EXISTS srs_reviews (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  card_id INTEGER NOT NULL,
  item_type TEXT NOT NULL,
  item_id TEXT NOT NULL,
  rating INTEGER NOT NULL,          -- 1=again, 2=hard, 3=good, 4=easy
  response_time_ms INTEGER,         -- 答题耗时

  -- 答题前后参数快照（用于审计和算法调优）
  difficulty_before REAL,
  stability_before REAL,
  interval_before INTEGER,
  difficulty_after REAL,
  stability_after REAL,
  interval_after INTEGER,

  reviewed_at DATETIME NOT NULL,

  FOREIGN KEY (user_id) REFERENCES user_profile(user_id),
  FOREIGN KEY (card_id) REFERENCES srs_cards(id)
);
```

## 三、核心算法

### 3.1 类型定义

```typescript
// services/SRSService.ts

export type Rating = 1 | 2 | 3 | 4; // again / hard / good / easy
export type CardState = 'new' | 'learning' | 'review' | 'relearning';

export interface SRSCard {
  id: number;
  user_id: string;
  item_type: string;
  item_id: string;
  difficulty: number;      // 1-10
  stability: number;       // 天
  retrievability: number;
  state: CardState;
  step: number;
  interval_days: number;
  due_date: string;
  last_reviewed_at: string | null;
  review_count: number;
  lapse_count: number;
}

export interface ReviewResult {
  difficulty: number;
  stability: number;
  interval_days: number;
  due_date: Date;
  new_state: CardState;
  new_step: number;
}
```

### 3.2 常量与参数

```typescript
// Learning 阶段步数（分钟）
const LEARNING_STEPS = [1, 10];

// Relearning 阶段步数（分钟）
const RELEARNING_STEPS = [10];

// 各 rating 对 difficulty / stability / interval 的影响系数
const RATING_MODIFIERS = {
  1: { difficulty: +1.5, stability: 0.0, interval: 0 },     // again: 难度↑, 稳定性归零
  2: { difficulty: +0.5, stability: 0.8, interval: 0.8 },   // hard:  难度微↑, 间隔缩短
  3: { difficulty: -0.2, stability: 1.0, interval: 1.0 },  // good:  难度微↓, 正常推进
  4: { difficulty: -0.5, stability: 1.3, interval: 1.5 },  // easy:  难度↓, 间隔拉长
};
```

### 3.3 核心计算函数

```typescript
export function calculateNextReview(
  card: SRSCard,
  rating: Rating
): ReviewResult {
  const mod = RATING_MODIFIERS[rating];
  const now = new Date();

  // ── 更新 difficulty（clamp 1-10）──
  let newDifficulty = card.difficulty + mod.difficulty;
  newDifficulty = Math.max(1, Math.min(10, newDifficulty));

  // ── 更新 stability ──
  let newStability: number;
  if (rating === 1) {
    newStability = 0.1; // 遗忘 → 稳定性归零
  } else {
    const goodBonus = 1 + (card.review_count / 10); // 复习次数越多越稳
    newStability = card.stability * mod.stability * goodBonus;
    newStability = Math.max(0.1, newStability);
  }

  // ── 计算间隔与新状态 ──
  let intervalDays: number;
  let newState: CardState = card.state;
  let newStep = card.step;

  if (card.state === 'new') {
    if (rating === 1) {
      intervalDays = 0;
      newState = 'learning';
      newStep = 0;
    } else {
      intervalDays = rating === 2 ? 1 : rating === 3 ? 1 : 3;
      newState = 'review';
      newStep = 0;
    }
  } else if (card.state === 'learning') {
    if (rating === 1) {
      newStep = 0;
      intervalDays = 0; // 1 分钟后
    } else if (rating >= 3) {
      newState = 'review';
      intervalDays = 1;
      newStep = 0;
    } else {
      newStep = Math.min(card.step + 1, LEARNING_STEPS.length - 1);
      intervalDays = 0;
    }
  } else if (card.state === 'review') {
    if (rating === 1) {
      newState = 'relearning';
      newStep = 0;
      intervalDays = 0; // 10 分钟后
    } else {
      intervalDays = Math.round(newStability * mod.interval);
      intervalDays = Math.max(1, Math.min(intervalDays, 365)); // clamp 1-365 天
    }
  } else if (card.state === 'relearning') {
    if (rating === 1) {
      newStep = 0;
      intervalDays = 0;
    } else if (rating >= 3) {
      newState = 'review';
      intervalDays = 1;
      newStep = 0;
    } else {
      newStep = Math.min(card.step + 1, RELEARNING_STEPS.length - 1);
      intervalDays = 0;
    }
  }

  // ── 计算 due_date ──
  let dueDate: Date;
  if (intervalDays === 0 && (newState === 'learning' || newState === 'relearning')) {
    // 分钟级调度
    const steps = newState === 'learning' ? LEARNING_STEPS : RELEARNING_STEPS;
    const minutes = steps[newStep] || 10;
    dueDate = new Date(now.getTime() + minutes * 60 * 1000);
  } else {
    dueDate = new Date(now.getTime() + intervalDays * 24 * 60 * 60 * 1000);
  }

  return {
    difficulty: newDifficulty,
    stability: newStability,
    interval_days: intervalDays,
    due_date: dueDate,
    new_state: newState,
    new_step: newStep,
  };
}
```

### 3.4 状态机图示

```
                    ┌──────────────────────────────────────┐
                    │                                      │
                    ▼                                      │
  [new] ──rating≥2──► [learning] ──rating≥3──► [review]   │
    │                    ▲                       │         │
    │                    │                       │         │
    └──rating=1──────────┘              rating=1 │         │
                                                ▼         │
                                         [relearning] ────┘
                                                │
                                       rating≥3 │
                                                ▼
                                          [review]
```

**规则**：
- `new` + again → 留在 learning，1 分钟后重来
- `learning` + good/easy → 毕业进入 review，间隔 1 天
- `review` + again → 跌入 relearning，10 分钟后重来
- `review` + hard/good/easy → 间隔按 stability × modifier 推进
- `relearning` + good/easy → 回到 review，间隔 1 天
- 间隔上限 **365 天**

## 四、提交复习

### 4.1 submitReview 完整实现

```typescript
export async function submitReview(
  userId: string,
  cardId: number,
  rating: Rating,
  responseTimeMs?: number
): Promise<{ card: SRSCard; xpAwarded: number }> {
  // 1. 读取当前卡片
  const card = await getCard(cardId);
  if (!card) throw new Error(`Card ${cardId} not found`);

  // 2. 保存答题前快照
  const before = {
    difficulty: card.difficulty,
    stability: card.stability,
    interval: card.interval_days,
  };

  // 3. 计算新参数
  const result = calculateNextReview(card, rating);

  // 4. 在一个事务中更新卡片 + 写流水 + 奖 XP
  await StorageService.transaction(async (tx) => {
    // 4a. 更新卡片
    await tx.execute(
      `UPDATE srs_cards SET
        difficulty = ?,
        stability = ?,
        retrievability = 1.0,
        state = ?,
        step = ?,
        interval_days = ?,
        due_date = ?,
        last_reviewed_at = ?,
        review_count = review_count + 1,
        lapse_count = lapse_count + ?,
        updated_at = ?
       WHERE id = ?`,
      [
        result.difficulty,
        result.stability,
        result.new_state,
        result.new_step,
        result.interval_days,
        result.due_date.toISOString(),
        new Date().toISOString(),
        rating === 1 ? 1 : 0,
        new Date().toISOString(),
        cardId,
      ]
    );

    // 4b. 写流水
    await tx.execute(
      `INSERT INTO srs_reviews
        (user_id, card_id, item_type, item_id, rating, response_time_ms,
         difficulty_before, stability_before, interval_before,
         difficulty_after, stability_after, interval_after, reviewed_at)
       VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
      [
        userId, cardId, card.item_type, card.item_id, rating, responseTimeMs || null,
        before.difficulty, before.stability, before.interval,
        result.difficulty, result.stability, result.interval_days,
        new Date().toISOString(),
      ]
    );
  });

  // 5. XP 奖励（在事务外，因为 awardXP 有自己的事务）
  let xpAwarded = 0;
  if (rating >= 3) {
    xpAwarded = 2;
    await awardXP(userId, 'review_correct', 2, card.item_type, card.item_id);
  } else if (rating === 2) {
    xpAwarded = 1;
    await awardXP(userId, 'review_hard', 1, card.item_type, card.item_id);
  }
  // rating === 1: 不奖 XP

  // 6. 检查每日任务（复习清空）
  const dueCount = await getDueCount(userId);
  if (dueCount === 0) {
    await updateDailyQuests(userId, 'review_cleared');
  }

  return { card: { ...card, ...result }, xpAwarded };
}
```

## 五、查询接口

### 5.1 获取今日到期卡片

```typescript
export async function getDueCards(
  userId: string,
  limit: number = 20
): Promise<SRSCard[]> {
  const now = new Date().toISOString();
  return StorageService.query<SRSCard>(
    `SELECT * FROM srs_cards
     WHERE user_id = ?
       AND due_date <= ?
       AND state != 'new'
     ORDER BY
       CASE state
         WHEN 'relearning' THEN 0
         WHEN 'learning'   THEN 1
         WHEN 'review'     THEN 2
       END,
       due_date ASC
     LIMIT ?`,
    [userId, now, limit]
  );
}
```

export async function getDueCount(userId: string): Promise<number> {
  const now = new Date().toISOString();
  const row = await StorageService.query<{ count: number }>(
    `SELECT COUNT(*) as count FROM srs_cards
     WHERE user_id = ? AND due_date <= ? AND state != 'new'`,
    [userId, now]
  );
  return row[0]?.count || 0;
}
```

### 5.4 获取复习统计

```typescript
export async function getReviewStats(userId: string): Promise<{
  totalCards: number;
  dueNow: number;
  newCards: number;
  learningCards: number;
  reviewCards: number;
  reviewedToday: number;
}> {
  const now = new Date().toISOString();
  const today = now.split('T')[0];

  const [totals, todayReviews] = await Promise.all([
    StorageService.query<{
      total: number; due: number; new_count: number;
      learning: number; review: number;
    }>(
      `SELECT
        COUNT(*) as total,
        SUM(CASE WHEN due_date <= ? AND state != 'new' THEN 1 ELSE 0 END) as due,
        SUM(CASE WHEN state = 'new' THEN 1 ELSE 0 END) as new_count,
        SUM(CASE WHEN state IN ('learning','relearning') THEN 1 ELSE 0 END) as learning,
        SUM(CASE WHEN state = 'review' THEN 1 ELSE 0 END) as review
       FROM srs_cards WHERE user_id = ?`,
      [now, userId]
    ),
    StorageService.query<{ count: number }>(
      `SELECT COUNT(*) as count FROM srs_reviews
       WHERE user_id = ? AND date(reviewed_at) = ?`,
      [userId, today]
    ),
  ]);

  const t = totals[0];
  return {
    totalCards: t?.total || 0,
    dueNow: t?.due || 0,
    newCards: t?.new_count || 0,
    learningCards: t?.learning || 0,
    reviewCards: t?.review || 0,
    reviewedToday: todayReviews[0]?.count || 0,
  };
}
```

## 七、复习 UI 流程

### 7.1 复习 Session 完整流程

```
首页 → [复习] 按钮（显示 due_count 角标）
  ↓
复习 Session 开始
  ↓
拉取 getDueCards(20) + getNewCards(5)
  ↓
混合排序：relearning 优先 → learning → review（按 due_date）
  ↓
逐卡展示（根据 item_type 渲染不同卡片组件）
  ↓
用户点击 "显示答案" → 显示背面
  ↓
用户选 rating（Again / Hard / Good / Easy）
  ↓
submitReview() → 即时反馈（显示下次间隔） → 下一卡
  ↓
全部完成 → Session 统计页
```

### 7.4 间隔预览计算（前端展示用）

```typescript
export function getIntervalPreview(card: SRSCard, rating: Rating): string {
  const result = calculateNextReview(card, rating);
  if (result.interval_days === 0) {
    const steps = card.state === 'learning' || card.state === 'new'
      ? LEARNING_STEPS : RELEARNING_STEPS;
    const minutes = steps[result.new_step] || 10;
    return minutes < 60 ? `< ${minutes}m` : `~${Math.round(minutes / 60)}h`;
  }
  if (result.interval_days === 1) return '~1d';
  if (result.interval_days < 30) return `~${result.interval_days}d`;
  const months = Math.round(result.interval_days / 30);
  return `~${months}mo`;
}
```

### 8.2 创建 Session

```typescript
export async function createReviewSession(userId: string): Promise<ReviewSession> {
  const [dueCards, newCards] = await Promise.all([
    getDueCards(userId, 20),
    getNewCards(userId, 5),
  ]);

  // 混合：到期卡优先，新卡穿插在后
  const cards = [...dueCards, ...newCards];

  return {
    sessionId: crypto.randomUUID ? crypto.randomUUID() : `rs_${Date.now()}_${Math.random().toString(36).slice(2)}`,
    userId,
    cards,
    currentIndex: 0,
    stats: { again: 0, hard: 0, good: 0, easy: 0 },
    startTime: new Date(),
  };
}
```

### 8.3 Session 完成后的级联

④ awardXP('session_complete', 10) — 板块完成奖励
⑤ 显示 Session 统计页
```

## 九、边界情况处理

| 场景 | 处理方式 |
|------|---------|
| 无到期卡 + 无新卡 | 显示"今天没有复习任务 🎉"，不进入 Session |
| 只有新卡无到期卡 | 正常进入，只展示新卡 |
| 复习中途退出 | 已提交的 rating 保留（每条独立事务），未提交的不丢 |
| 同一张卡同一天多次到期 | 只出现一次（due_date 更新后不再匹配） |
| 卡片 item 被删除（种子更新） | `item_id` 查不到时显示"内容已更新"，跳过该卡 |
| 用户切换 CEFR 等级 | 不影响已有卡片，新卡按新等级入队 |
| 离线 | 全部本地操作，无影响 |
| 大量到期（>50 张） | 分 Session，每次最多 25 张，提示"剩余 X 张明天继续" |

## 十、补进 `.cursorrules` 的规则

```markdown
## SRS 复习队列规范

1. 使用简化 FSRS 算法，4 档 rating（again=1 / hard=2 / good=3 / easy=4）
2. 所有学习项统一存 srs_cards 表，通过 item_type + item_id 区分来源
3. 新卡 state='new'，首次复习后进入 learning → review
4. again 永远回到 learning/relearning，间隔重置为分钟级
5. 复习间隔上限 365 天，下限 1 天（review 状态）
6. 每次 submitReview() 必须写 srs_reviews 流水（含前后参数快照）
7. 各板块在"用户确认学习"时调用 enrollCard()（INSERT OR IGNORE 防重复）
8. 复习 Session 每轮最多 25 张（20 due + 5 new）
9. rating 按钮必须显示下次间隔预览（getIntervalPreview）
10. 复习完成触发：XP 奖励 + streak 更新 + 每日任务检查
11. 离线可用，不依赖网络
12. srs_cards 查询必须带 user_id + due_date 索引
13. 到期卡排序：relearning > learning > review，同级按 due_date ASC
14. Session 中途退出不丢已提交数据（每条独立事务）
```
