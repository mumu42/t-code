# LinguaFlow — 激励与留存层 V2：能力成长感知系统

> 本文档替代原有的「徽章/成就系统」，用 XP + 12 级能力等级映射用户「我能用英语做什么」，直接挂钩 B1→B2 职场技术人的职业目标。

---

## 一、设计思路

把「积分/经验」翻译成「我能在什么场景做什么事」。

用户每得 1 分，不只是数字 +1，而是：

1. 分数实时 +1（即时反馈，多巴胺）
2. 分数推动「能力等级」变化
3. 等级变化解锁一句**具体的职场能力描述**（"你现在已经能读懂英文技术 RFC 了"）
4. 等级变化时做一次**轻量展示**（首页顶部 banner 或卡片翻转，不弹窗打断）

### 与定级模块的关系

| 关系 | 说明 |
|------|------|
| 定级 `current_level` (CEFR) | 决定**内容难度**（给你什么题） |
| 激励 `current_level_index` (0-11) | 决定**能力感知展示**（你多厉害了） |
| 两者独立 | CEFR 是客观定级，XP 是主观成长感 |
| 映射关系 | `LEVELS[level_index].cefrRange` 近似对齐，但不强制同步 |

**设计意图**：用户可能 CEFR 定级 B1，但 XP 等级到了 L5（Skilled），展示"你比同级别的人进步更快"——这是正反馈，不是矛盾。

## 二、积分体系（XP）

### 2.1 积分来源

| 行为 | XP | 说明 |
|------|-----|------|
| 完成 1 题（正确） | +2 | 基础 |
| 完成 1 题（错误但已标记） | +1 | 鼓励"错了也学" |
| 完成 1 个板块 session | +10 | 板块完成奖励 |
| 复习队列清空 | +15 | 复习激励 |
| 连续正确 5 题 | +5 | 连击奖励 |
| 每日任务全完成 | +20 | 日活激励 |
| streak 每满 7 天 | +30 | 里程碑 |
| 首次接触新语法点 | +3 | 探索奖励 |

**每日上限：150 XP**（防止刷分，但宽松够用）

### 2.2 等级阈值

| 等级 | 累计 XP | 所需增量 |
|------|---------|---------|
| L0 | 0 | — |
| L1 | 50 | 50 |
| L2 | 150 | 100 |
| L3 | 300 | 150 |
| L4 | 500 | 200 |
| L5 | 800 | 300 |
| L6 | 1200 | 400 |
| L7 | 1700 | 500 |
| L8 | 2300 | 600 |
| L9 | 3000 | 700 |
| L10 | 4000 | 1000 |

## 四、核心服务：`XPService.ts`

```typescript
// services/XPService.ts

import { StorageService } from './StorageService';
import { LEVELS, LevelDef } from '../constants/levels';

const DAILY_XP_CAP = 150;

const XP_THRESHOLDS = [
  0, 50, 150, 300, 500, 800, 1200, 1700, 2300, 3000, 4000, 5500,
];

export interface AwardResult {
  totalXP: number;
  gained: number;         // 本次实际获得（可能被上限截断）
  leveledUp: boolean;
  newLevel?: LevelDef;
  previousLevelIndex?: number;
}

export async function awardXP(
  userId: string,
  source: string,
  amount: number,
  board?: string,
  relatedId?: string
): Promise<AwardResult> {
  // 1. 检查每日上限
  const today = new Date().toISOString().split('T')[0];
  const todayRow = await StorageService.query<{ total: number }>(
    `SELECT COALESCE(SUM(amount), 0) as total FROM xp_log
     WHERE user_id = ? AND date(created_at) = ?`,
    [userId, today]
  );
  const usedToday = todayRow[0]?.total || 0;
  const actualAmount = Math.max(0, Math.min(amount, DAILY_XP_CAP - usedToday));

  if (actualAmount === 0) {
    const profile = await StorageService.query<{ total_xp: number }>(
      `SELECT total_xp FROM user_profile WHERE user_id = ?`, [userId]
    );
    return { totalXP: profile[0]?.total_xp || 0, gained: 0, leveledUp: false };
  }

  // 2. 写流水
  await StorageService.execute(
    `INSERT INTO xp_log (user_id, source, amount, board, related_id, created_at)
     VALUES (?, ?, ?, ?, ?, ?)`,
    [userId, source, actualAmount, board || null, relatedId || null, new Date().toISOString()]
  );

  // 3. 更新总 XP
  await StorageService.execute(
    `UPDATE user_profile SET total_xp = total_xp + ? WHERE user_id = ?`,
    [actualAmount, userId]
  );

  // 4. 检查升级
  const profile = await StorageService.query<{
    total_xp: number;
    current_level_index: number;
  }>(
    `SELECT total_xp, current_level_index FROM user_profile WHERE user_id = ?`,
    [userId]
  );
  const totalXP = profile[0]!.total_xp;
  const oldIdx = profile[0]!.current_level_index;
  const newIdx = calculateLevelIndex(totalXP);

  if (newIdx > oldIdx) {
    await StorageService.execute(
      `UPDATE user_profile SET current_level_index = ? WHERE user_id = ?`,
      [newIdx, userId]
    );
    await StorageService.execute(
      `INSERT OR IGNORE INTO level_unlocks (user_id, level_index, unlocked_at)
       VALUES (?, ?, ?)`,
      [userId, newIdx, new Date().toISOString()]
    );
    return {
      totalXP,
      gained: actualAmount,
      leveledUp: true,
      newLevel: LEVELS[newIdx],
      previousLevelIndex: oldIdx,
    };
  }

  return { totalXP, gained: actualAmount, leveledUp: false };
}

export function calculateLevelIndex(totalXP: number): number {
  for (let i = XP_THRESHOLDS.length - 1; i >= 0; i--) {
    if (totalXP >= XP_THRESHOLDS[i]) return i;
  }
  return 0;
}

export function getXPForNextLevel(totalXP: number): {
  current: number;
  next: number;
  progress: number; // 0-1
} {
  const idx = calculateLevelIndex(totalXP);
  const current = XP_THRESHOLDS[idx];
  const next = idx < XP_THRESHOLDS.length - 1
    ? XP_THRESHOLDS[idx + 1]
    : XP_THRESHOLDS[idx];
  const progress = next > current
    ? (totalXP - current) / (next - current)
    : 1;
  return { current, next, progress };
}

export async function getUnviewedLevelUps(
  userId: string
): Promise<LevelDef[]> {
  const rows = await StorageService.query<{ level_index: number }>(
    `SELECT level_index FROM level_unlocks
     WHERE user_id = ? AND viewed = 0 ORDER BY level_index ASC`,
    [userId]
  );
  return rows.map(r => LEVELS[r.level_index]);
}

export async function markLevelUpsViewed(
  userId: string
): Promise<void> {
  await StorageService.execute(
    `UPDATE level_unlocks SET viewed = 1 WHERE user_id = ? AND viewed = 0`,
    [userId]
  );
}
```

### 6.1 数据库

```sql

--   streak_days INTEGER DEFAULT 0

CREATE TABLE IF NOT EXISTS streak_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  date TEXT NOT NULL,
  sessions_count INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL,
  UNIQUE(user_id, date),
  FOREIGN KEY (user_id) REFERENCES user_profile(user_id)
);

  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL UNIQUE,
  quantity INTEGER NOT NULL DEFAULT 0,
  last_awarded_at DATETIME,
  FOREIGN KEY (user_id) REFERENCES user_profile(user_id)
);
```

### 6.2 冻结卡规则

| 规则 | 值 |
|------|-----|
| 获得方式 | 连续学习 7 天奖励 1 张 |
| 上限 | 3 张 |
| 使用条件 | streak 断了（昨天没练）自动消耗 |
| 用户手动使用 | 不支持（防滥用） |
| 有效期 | 永久 |

### 6.3 服务代码

```typescript
// services/StreakService.ts

export async function updateStreak(userId: string): Promise<{
  streak: number;
  changed: boolean;
  reason: 'first_day' | 'continued' | 'already_counted' | 'freeze_used' | 'broken';
}> {
  const today = new Date().toISOString().split('T')[0];
  const profile = await StorageService.query<{
    streak_days: number;
    last_active_date: string | null;
  }>(`SELECT streak_days, last_active_date FROM user_profile WHERE user_id = ?`, [userId]);

  const current = profile[0];
  if (!current) return { streak: 0, changed: false, reason: 'already_counted' };

  const lastDate = current.last_active_date;
  let newStreak = current.streak_days;
  let changed = false;
  let reason: any = 'already_counted';

  if (!lastDate) {
    newStreak = 1; changed = true; reason = 'first_day';
  } else if (lastDate === today) {
    reason = 'already_counted';
  } else {
    const diffDays = Math.floor(
      (new Date(today).getTime() - new Date(lastDate).getTime()) / 86400000
    );
    if (diffDays === 1) {
      newStreak += 1; changed = true; reason = 'continued';
    } else if (diffDays > 1) {
      const freeze = await getStreakFreeze(userId);
      if (freeze && freeze.quantity > 0) {
        await consumeStreakFreeze(userId);
        newStreak = 1; changed = true; reason = 'freeze_used';
      } else {
        newStreak = 1; changed = true; reason = 'broken';
      }
    }
  }

  if (changed) {
    await StorageService.execute(
      `UPDATE user_profile SET streak_days = ?, last_active_date = ? WHERE user_id = ?`,
      [newStreak, today, userId]
    );
    await StorageService.execute(
      `INSERT OR IGNORE INTO streak_log (user_id, date, sessions_count, created_at)
       VALUES (?, ?, 1, ?)`,
      [userId, today, new Date().toISOString()]
    );
    // 每 7 天奖励冻结卡
    if (newStreak > 0 && newStreak % 7 === 0) {
      await awardStreakFreeze(userId);
      await awardXP(userId, 'streak_bonus', 30, undefined, String(newStreak));
    }
  }

  return { streak: newStreak, changed, reason };
}

async function getStreakFreeze(userId: string) {
  const row = await StorageService.query<{ quantity: number }>(
    `SELECT quantity FROM streak_freezes WHERE user_id = ?`, [userId]
  );
  return row[0] || null;
}

async function awardStreakFreeze(userId: string): Promise<void> {
  await StorageService.execute(
    `INSERT INTO streak_freezes (user_id, quantity, last_awarded_at)
     VALUES (?, 1, ?)
     ON CONFLICT(user_id) DO UPDATE SET
       quantity = MIN(quantity + 1, 3),
       last_awarded_at = excluded.last_awarded_at`,
    [userId, new Date().toISOString()]
  );
}

async function consumeStreakFreeze(userId: string): Promise<void> {
  await StorageService.execute(
    `UPDATE streak_freezes SET quantity = quantity - 1
     WHERE user_id = ? AND quantity > 0`, [userId]
  );
}
```

## 七、每日任务（Daily Quests）

### 7.1 数据库

```sql
CREATE TABLE IF NOT EXISTS daily_quests (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  quest_date TEXT NOT NULL,
  quest_1_done INTEGER DEFAULT 0,   -- 完成 1 个板块练习
  quest_2_done INTEGER DEFAULT 0,   -- 清空复习队列
  quest_3_done INTEGER DEFAULT 0,   -- 完成 2 个不同板块
  all_completed INTEGER DEFAULT 0,
  reward_claimed INTEGER DEFAULT 0,
  created_at DATETIME NOT NULL,
  UNIQUE(user_id, quest_date),
  FOREIGN KEY (user_id) REFERENCES user_profile(user_id)
);
```

### 7.2 任务定义

| 任务 | 条件 | XP 奖励 |
|------|------|---------|
| Quest 1 | 完成 1 个板块练习 | +5 |
| Quest 2 | 清空复习队列 | +5 |
| Quest 3 | 同一天完成 2 个不同板块 | +10 |
| 全部完成 | 3 个全 done | +20 + 1 冻结卡 |

### 7.3 服务代码

```typescript
// services/DailyQuestService.ts

export async function updateDailyQuests(
  userId: string,
  event: 'session_complete' | 'review_cleared',
  board?: string
): Promise<void> {
  const today = new Date().toISOString().split('T')[0];

  await StorageService.execute(
    `INSERT OR IGNORE INTO daily_quests (user_id, quest_date, created_at)
     VALUES (?, ?, ?)`,
    [userId, today, new Date().toISOString()]
  );

  if (event === 'session_complete') {
    await StorageService.execute(
      `UPDATE daily_quests SET quest_1_done = 1
       WHERE user_id = ? AND quest_date = ?`, [userId, today]
    );
    await awardXP(userId, 'daily_quest', 5, board);

    // 检查今天完成了几个不同板块
    const sessions = await StorageService.query<{ board: string }>(
      `SELECT DISTINCT board FROM (
        SELECT 'vocab' as board FROM vocab_sessions WHERE user_id = ? AND date(created_at) = ?
        UNION SELECT 'listening' FROM listening_sessions WHERE user_id = ? AND date(created_at) = ?
        UNION SELECT 'reading' FROM reading_sessions WHERE user_id = ? AND date(created_at) = ?
        UNION SELECT 'speaking' FROM speaking_sessions WHERE user_id = ? AND date(created_at) = ?
        UNION SELECT 'writing' FROM writing_sessions WHERE user_id = ? AND date(created_at) = ?
      )`,
      [userId, today, userId, today, userId, today, userId, today, userId, today]
    );
    if (sessions.length >= 2) {
      await StorageService.execute(
        `UPDATE daily_quests SET quest_3_done = 1
         WHERE user_id = ? AND quest_date = ? AND quest_3_done = 0`, [userId, today]
      );
      await awardXP(userId, 'daily_quest', 10, board);
    }

  } else if (event === 'review_cleared') {
    await StorageService.execute(
      `UPDATE daily_quests SET quest_2_done = 1
       WHERE user_id = ? AND quest_date = ? AND quest_2_done = 0`, [userId, today]
    );
    await awardXP(userId, 'daily_quest', 5, 'review');
  }

  // 检查全部完成
  const row = await StorageService.query<{
    quest_1_done: number; quest_2_done: number; quest_3_done: number;
    all_completed: number;
  }>(
    `SELECT quest_1_done, quest_2_done, quest_3_done, all_completed
     FROM daily_quests WHERE user_id = ? AND quest_date = ?`, [userId, today]
  );
  const r = row[0];
  if (r && r.quest_1_done && r.quest_2_done && r.quest_3_done && !r.all_completed) {
    await StorageService.execute(
      `UPDATE daily_quests SET all_completed = 1 WHERE user_id = ? AND quest_date = ?`,
      [userId, today]
    );
    await awardXP(userId, 'daily_quest_all', 20);
    // 奖励冻结卡
    await StorageService.execute(
      `INSERT INTO streak_freezes (user_id, quantity)
       VALUES (?, 1)
       ON CONFLICT(user_id) DO UPDATE SET quantity = MIN(quantity + 1, 3)`,
      [userId]
    );
  }
}
```

## 八、本地通知

### 8.1 选型

`expo-notifications`（iOS / Android / Web 均支持）

### 8.2 通知策略

| 时机 | 内容 | 频率 |
|------|------|------|
| 每天 20:00 | "你有 N 个复习待完成 🔥 streak X 天" | 每天 1 次 |
| streak 断了 | "昨天没练哦，今天补上？" | 仅断 streak 时 |
| 升级 | "🎉 你解锁了新等级：Skilled！" | 仅升级时 |

### 8.3 权限请求时机

**第 3 次练习完成后**请求通知权限（不是首次启动就弹，用户反感）。

### 8.4 服务代码

```typescript
// services/NotificationService.ts

import * as Notifications from 'expo-notifications';

export async function requestNotificationPermission(): Promise<boolean> {
  const { status: existing } = await Notifications.getPermissionsAsync();
  if (existing === 'granted') return true;
  const { status } = await Notifications.requestPermissionsAsync();
  return status === 'granted';
}

export async function scheduleDailyReminder(hour = 20, minute = 0): Promise<void> {
  await Notifications.cancelAllScheduledNotificationsAsync();
  await Notifications.scheduleNotificationAsync({
    content: {
      title: 'Time to practice! 🔥',
      body: 'Keep your streak alive. Just 5 minutes a day.',
      sound: true,
    },
    trigger: { hour, minute, repeats: true },
  });
}

export async function sendLevelUpNotification(levelName: string): Promise<void> {
  await Notifications.scheduleNotificationAsync({
    content: {
      title: `🎉 Level Up: ${levelName}!`,
      body: 'Tap to see what you can do now.',
      sound: true,
    },
    trigger: null,
  });
}

export async function cancelAllReminders(): Promise<void> {
  await Notifications.cancelAllScheduledNotificationsAsync();
}
```

## 十、Service 调用时机汇总

| 时机 | 调用 | 说明 |
|------|------|------|

| 通知调度 | `scheduleDailyReminder(20, 0)` | 用户授权后 |

## 十三、MVP 不做的事（明确边界）

| 不做 | 理由 |
|------|------|
| 徽章/成就系统 | 用 XP + 能力等级替代，更有意义 |
| 排行榜（Leaderboard） | 无后端，本地排行榜没意义 |
| 虚拟货币 / 宝石 | 维护成本高，MVP 不需要 |
| 好友系统 | 无后端 |
| 每日能量限制 | 你不是付费产品，别学 Duolingo 逼氪 |
| 推送通知个性化 | MVP 固定 20:00，不按用户习惯调 |
| 升级动画/特效 | 先有功能，V2 加动效 |
| XP 分享到社交平台 | V2 再加 |
