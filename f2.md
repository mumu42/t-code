# LinguaFlow — 跨平台 TTS 音频方案（Web / iOS / Android / Desktop）

> 本文档定义 LinguaFlow 英语学习 App 在 **Web、iOS、Android、桌面（Electron/React Native Windows+macOS）** 四端的文本转语音（TTS）与录音方案。
> 核心原则：**一套统一 API 封装，各端底层引擎可替换，业务层零感知。**

---

## 一、平台能力矩阵

| 能力 | Web | iOS | Android | Desktop (Electron) | Desktop (RN Windows/macOS) |
|------|-----|-----|---------|-------------------|---------------------------|
| TTS 播句 | `speechSynthesis` (Web Speech API) | `AVSpeechSynthesizer` (via expo-speech) | `TextToSpeech` (via expo-speech) | `speechSynthesis` (Chromium 内置) | Windows: `Windows.Media.SpeechSynthesis` (UWP) / macOS: `NSSpeechSynthesizer` |
| 暂停/恢复 | ✅ | ✅ | ❌ (expo-speech 不支持) | ✅ | ✅ |
| 语速控制 | ✅ rate 0.1–10 | ✅ rate 0.5–2.0 | ✅ rate 0.5–2.0 | ✅ | ✅ |
| 音高控制 | ✅ pitch 0–2 | ✅ pitch 0.5–2.0 | ✅ pitch 0.5–2.0 | ✅ | ⚠️ 平台相关 |
| 音色选择 | ✅ `getVoices()` | ✅ `getAvailableVoicesAsync()` | ✅ `getAvailableVoicesAsync()` | ✅ | ⚠️ 有限 |
| 逐词回调 | ✅ `onboundary` | ✅ `onBoundary` | ⚠️ 部分支持 | ✅ | ❌ |
| 静音模式播放 | ✅ (浏览器策略) | ❌ (静音开关物理限制) | ✅ | ✅ | ✅ |
| 离线可用 | ✅ (系统语音) | ✅ (系统语音) | ✅ (系统语音, 部分需下载) | ✅ | ✅ |
| 单次字数上限 | 无硬限 | 无硬限 | **4000 字符** | 无硬限 | 无硬限 |
| 录音 | `MediaRecorder` API | `expo-av` | `expo-av` | `MediaRecorder` (Chromium) | RN: `react-native-audio-recorder-player` |

### 关键平台差异总结

1. **Android 不支持 pause/resume**（expo-speech 限制）→ 业务层用 stop + 重新 speak 模拟
2. **iOS 静音开关**会导致 expo-speech 无声 → 提示用户关闭静音，或设置 `useApplicationAudioSession: false`
3. **Web 浏览器**需要用户手势（如点击）后才能首次触发 speechSynthesis → 在首次点击"播放"按钮时初始化
4. **Firefox** 对 Web Speech API 支持不完整 → 降级提示"请使用 Chrome/Edge/Safari"
5. **Desktop Electron** 直接用 Chromium 的 `speechSynthesis`，与 Web 端代码完全一致

## 二、统一架构设计

```
┌─────────────────────────────────────────────────────────────────┐
│                      业务层（各板块 Service）                      │
│   ListeningService / SpeakingService / WritingService ...       │
│                                                                 │
│   import { ttsService } from '../services/TTSService';          │
│   await ttsService.speak(text, { rate: 0.9, accent: 'us' });    │
└──────────────────────────┬──────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│                   TTSService（统一接口层）                        │
│                                                                 │
│   interface ITTSService {                                       │
│     speak(text, options?): Promise<void>;                       │
│     stop(): void;                                              │
│     pause(): void;                                             │
│     resume(): void;                                            │
│     isSpeaking(): boolean;                                     │
│     getVoices(): Promise<TTSVoice[]>;                          │
│   }                                                            │
│                                                                 │
│   ← 根据 Platform.OS 自动选择实现                                │
└──────┬──────────┬──────────┬──────────┬──────────┬──────────────┘
       ↓          ↓          ↓          ↓          ↓
┌──────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌──────────────┐
│ WebTTS   │ │ IOSTTS │ │AndTTS  │ │ElecTTS │ │ RNDesktopTTS │
│Adapter   │ │Adapter │ │Adapter │ │Adapter │ │ Adapter      │
│          │ │        │ │        │ │        │ │              │
│speech-   │ │expo-   │ │expo-   │ │speech- │ │Windows: UWP  │
│Synthesis │ │speech  │ │speech  │ │Synthesis│ │macOS: NSSpeech│
│(Web API) │ │(native)│ │(native)│ │(Chromium)│ │(native module)│
└──────────┘ └────────┘ └────────┘ └────────┘ └──────────────┘
```

**核心思想**：`TTSService` 是唯一入口，内部通过 `Platform.OS` + 环境检测自动选择 Adapter。业务代码永远只 `import { ttsService }`，不关心底层。

## 三、统一接口定义

```typescript
// services/tts/types.ts

export interface TTSOptions {
  rate?: number;         // 语速倍率，默认 1.0（0.5–2.0）
  pitch?: number;        // 音高，默认 1.0（0.5–2.0）
  accent?: 'us' | 'uk' | 'au';  // 口音偏好
  voiceId?: string;      // 指定音色（从 getVoices 获取的 identifier）
  onWordBoundary?: (word: string, offset: number) => void;  // 逐词回调（可选）
  onStart?: () => void;
  onDone?: () => void;
  onError?: (error: Error) => void;
}

export interface TTSVoice {
  identifier: string;
  name: string;
  language: string;      // BCP 47, e.g., 'en-US'
  quality?: 'default' | 'enhanced' | 'premium';
  isNetworkRequired?: boolean;
}

export interface ITTSService {
  /** 朗读文本（加入队列，前一个播完自动播下一个） */
  speak(text: string, options?: TTSOptions): Promise<void>;
  
  /** 立即停止并清空队列 */
  stop(): void;
  
  /** 暂停（Android 不支持时自动降级为 stop） */
  pause(): void;
  
  /** 恢复（Android 不支持时自动降级为重新 speak） */
  resume(): void;
  
  /** 当前是否正在播放 */
  isSpeaking(): boolean;
  
  /** 获取可用音色列表 */
  getVoices(): Promise<TTSVoice[]>;
  
  /** 预检：当前环境是否支持 TTS */
  isSupported(): boolean;
}
```

## 四、各端 Adapter 实现

### 4.1 Web Adapter（`speechSynthesis`）

```typescript
// services/tts/WebTTSAdapter.ts

export class WebTTSAdapter implements ITTSService {
  private synth: SpeechSynthesis;
  private queue: { text: string; options: TTSOptions; resolve: () => void }[] = [];
  private currentUtterance: SpeechSynthesisUtterance | null = null;
  private isPaused: boolean = false;

  constructor() {
    this.synth = window.speechSynthesis;
  }

  isSupported(): boolean {
    return 'speechSynthesis' in window && 'SpeechSynthesisUtterance' in window;
  }

  async speak(text: string, options: TTSOptions = {}): Promise<void> {
    if (!this.isSupported()) {
      console.warn('[WebTTS] speechSynthesis not supported');
      options.onError?.(new Error('TTS not supported'));
      return;
    }

    return new Promise((resolve) => {
      const utterance = new SpeechSynthesisUtterance(text);
      utterance.rate = options.rate ?? 1.0;
      utterance.pitch = options.pitch ?? 1.0;
      utterance.lang = this.resolveLang(options.accent);

      // 音色选择
      if (options.voiceId) {
        const voices = this.synth.getVoices();
        const voice = voices.find(v => v.voiceURI === options.voiceId);
        if (voice) utterance.voice = voice;
      }

      // 事件
      utterance.onstart = () => options.onStart?.();
      utterance.onend = () => {
        options.onDone?.();
        resolve();
        this.processQueue();
      };
      utterance.onerror = (e) => {
        options.onError?.(new Error(e.error));
        resolve();
        this.processQueue();
      };
      utterance.onboundary = (e) => {
        if (e.name === 'word' && options.onWordBoundary) {
          options.onWordBoundary(e.target.text.slice(e.charIndex, e.charIndex + e.charLength), e.charIndex);
        }
      };

      this.queue.push({ text, options, resolve });
      if (!this.synth.speaking) this.processQueue();
    });
  }

  private processQueue(): void {
    if (this.queue.length === 0) return;
    const { options } = this.queue.shift()!;
    // 实际 utterance 已在 speak() 中创建，这里触发播放
    this.synth.speak(this.currentUtterance!);
  }

  stop(): void {
    this.synth.cancel();
    this.queue = [];
    this.currentUtterance = null;
    this.isPaused = false;
  }

  pause(): void {
    if (this.synth.speaking && !this.isPaused) {
      this.synth.pause();
      this.isPaused = true;
    }
  }

  resume(): void {
    if (this.isPaused) {
      this.synth.resume();
      this.isPaused = false;
    }
  }

  isSpeaking(): boolean {
    return this.synth.speaking;
  }

  async getVoices(): Promise<TTSVoice[]> {
    let voices = this.synth.getVoices();
    // Chrome 异步加载 voices
    if (voices.length === 0) {
      voices = await new Promise<SpeechSynthesisVoice[]>((resolve) => {
        this.synth.onvoiceschanged = () => resolve(this.synth.getVoices());
        setTimeout(() => resolve(this.synth.getVoices()), 2000);
      });
    }
    return voices
      .filter(v => v.lang.startsWith('en'))
      .map(v => ({
        identifier: v.voiceURI,
        name: v.name,
        language: v.lang,
        quality: v.localService ? 'default' : 'enhanced',
      }));
  }

  private resolveLang(accent?: string): string {
    switch (accent) {
      case 'uk': return 'en-GB';
      case 'au': return 'en-AU';
      default: return 'en-US';
    }
  }
}
```

### 4.2 iOS / Android Adapter（`expo-speech`）

```typescript
// services/tts/NativeTTSAdapter.ts
import * as Speech from 'expo-speech';
import { Platform } from 'react-native';

export class NativeTTSAdapter implements ITTSService {
  private isPaused: boolean = false;
  private pausedText: string | null = null;
  private pausedOptions: TTSOptions | null = null;

  isSupported(): boolean {
    return true; // expo-speech 在 iOS/Android 始终可用
  }

  async speak(text: string, options: TTSOptions = {}): Promise<void> {
    // Android 4000 字符限制
    if (Platform.OS === 'android' && text.length > Speech.maxSpeechInputLength) {
      const chunks = this.chunkText(text, Speech.maxSpeechInputLength);
      for (const chunk of chunks) {
        await this.speakChunk(chunk, options);
      }
      return;
    }

    return this.speakChunk(text, options);
  }

  private speakChunk(text: string, options: TTSOptions): Promise<void> {
    return new Promise((resolve) => {
      const voice = this.resolveVoiceId(options.accent, options.voiceId);

      Speech.speak(text, {
        rate: options.rate ?? 1.0,
        pitch: options.pitch ?? 1.0,
        voice,
        language: this.resolveLang(options.accent),
        // iOS: 不静音其他音频；允许后台播放
        ...(Platform.OS === 'ios' && { useApplicationAudioSession: false }),
        onStart: () => options.onStart?.(),
        onDone: () => {
          options.onDone?.();
          resolve();
        },
        onError: (err) => {
          options.onError?.(err);
          resolve(); // 不 reject，静默失败
        },
        onBoundary: (ev) => {
          if (options.onWordBoundary && ev.text) {
            options.onWordBoundary(ev.text, ev.charIndex ?? 0);
          }
        },
      });
    });
  }

  stop(): void {
    Speech.stop();
    this.isPaused = false;
    this.pausedText = null;
    this.pausedOptions = null;
  }

  pause(): void {
    if (Platform.OS === 'ios') {
      Speech.pause();
      this.isPaused = true;
    } else {
      // Android 不支持 pause → 记录位置，stop 当前
      this.isPaused = true;
      Speech.stop();
    }
  }

  resume(): void {
    if (Platform.OS === 'ios' && this.isPaused) {
      Speech.resume();
      this.isPaused = false;
    }
    // Android: 业务层需要重新调用 speak()
  }

  isSpeaking(): boolean {
    // expo-speech 的 isSpeakingAsync 是异步的，这里用同步近似
    return this.isPaused;
  }

  async getVoices(): Promise<TTSVoice[]> {
    const voices = await Speech.getAvailableVoicesAsync();
    return voices
      .filter(v => v.language.startsWith('en'))
      .map(v => ({
        identifier: v.identifier,
        name: v.name || v.identifier,
        language: v.language,
        quality: v.quality === 500 ? 'enhanced' : 'default',
        isNetworkRequired: v.networkConnectionRequired,
      }));
  }

  private chunkText(text: string, maxLen: number): string[] {
    const sentences = text.match(/[^.!?]+[.!?]+/g) || [text];
    const chunks: string[] = [];
    let current = '';
    for (const sentence of sentences) {
      if (current.length + sentence.length > maxLen) {
        chunks.push(current.trim());
        current = sentence;
      } else {
        current += ' ' + sentence;
      }
    }
    if (current.trim()) chunks.push(current.trim());
    return chunks;
  }

  private resolveLang(accent?: string): string {
    switch (accent) {
      case 'uk': return 'en-GB';
      case 'au': return 'en-AU';
      default: return 'en-US';
    }
  }

  private resolveVoiceId(accent?: string, explicitId?: string): string | undefined {
    if (explicitId) return explicitId;
    // 平台相关的默认音色在 getVoices() 后由业务层缓存选择
    return undefined; // 让系统选默认
  }
}
```

### 4.4 React Native Windows / macOS Adapter

```typescript
// services/tts/RNDesktopTTSAdapter.ts
// react-native-windows 和 react-native-macos 通过社区模块 react-native-tts 支持

import Tts from 'react-native-tts';

export class RNDesktopTTSAdapter implements ITTSService {
  private initialized: boolean = false;

  constructor() {
    this.init();
  }

  private async init(): Promise<void> {
    try {
      await Tts.getInitStatus();
      this.initialized = true;
    } catch {
      // 初始化失败，speak 时会重试
    }
  }

  isSupported(): boolean {
    return true;
  }

  async speak(text: string, options: TTSOptions = {}): Promise<void> {
    if (!this.initialized) await this.init();

    return new Promise((resolve) => {
      const lang = this.resolveLang(options.accent);

      // Windows/macOS 用 react-native-text-to-speech 的统一 API
      Tts.speak(text, {
        // iOS/macOS 用 iosVoiceId，Windows 用语言代码
        ...(Platform.OS === 'macos' && options.voiceId && { iosVoiceId: options.voiceId }),
        rate: options.rate ?? 1.0,
        ...(options.pitch && { pitch: options.pitch }),
      });

      // 监听完成事件
      const finishListener = Tts.addEventListener('tts-finish', () => {
        options.onDone?.();
        finishListener.remove();
        resolve();
      });

      const cancelListener = Tts.addEventListener('tts-cancel', () => {
        finishListener.remove();
        cancelListener.remove();
        resolve();
      });
    });
  }

  stop(): void {
    Tts.stop();
  }

  pause(): void {
    // react-native-tts 在 Windows/macOS 暂不支持 pause
    // 降级为 stop
    Tts.stop();
  }

  resume(): void {
    // 不支持，业务层重新 speak
  }

  isSpeaking(): boolean {
    return false; // 无同步 API
  }

  async getVoices(): Promise<TTSVoice[]> {
    const voices = await Tts.voices();
    return voices
      .filter((v: any) => v.language?.startsWith('en'))
      .map((v: any) => ({
        identifier: v.id,
        name: v.name || v.id,
        language: v.language,
        quality: v.quality >= 500 ? 'enhanced' : 'default',
      }));
  }

  private resolveLang(accent?: string): string {
    switch (accent) {
      case 'uk': return 'en-GB';
      case 'au': return 'en-AU';
      default: return 'en-US';
    }
  }
}
```

## 五、Adapter 工厂（自动选择）

```typescript
// services/tts/TTSServiceFactory.ts
import { Platform } from 'react-native';

export function createTTSService(): ITTSService {
  // Web 环境（包括 Electron renderer）
  if (Platform.OS === 'web') {
    // 检测是否在 Electron 中
    const isElectron = typeof window !== 'undefined' && 
                       (window as any).process?.type === 'renderer';
    // Electron 和 Web 都用 Web Speech API，行为一致
    return new WebTTSAdapter();
  }

  // iOS / Android
  if (Platform.OS === 'ios' || Platform.OS === 'android') {
    return new NativeTTSAdapter();
  }

  // React Native Windows / macOS
  if (Platform.OS === 'windows' || Platform.OS === 'macos') {
    return new RNDesktopTTSAdapter();
  }

  // 兜底：返回 NoOp
  console.warn(`[TTS] Unsupported platform: ${Platform.OS}`);
  return new NoOpTTSAdapter();
}

// NoOp 兜底
class NoOpTTSAdapter implements ITTSService {
  isSupported() { return false; }
  async speak() { console.warn('[TTS] NoOp speak called'); }
  stop() {}
  pause() {}
  resume() {}
  isSpeaking() { return false; }
  async getVoices() { return []; }
}
```

## 六、业务层统一入口

```typescript
// services/TTSService.ts

import { createTTSService } from './tts/TTSServiceFactory';
import type { ITTSService, TTSOptions } from './tts/types';

class TTSServiceWrapper implements ITTSService {
  private adapter: ITTSService;

  constructor() {
    this.adapter = createTTSService();
  }

  async speak(text: string, options: TTSOptions = {}): Promise<void> {
    // 语速按用户 level 自动调整（如果没传 rate）
    if (options.rate === undefined) {
      options.rate = this.getDefaultRate();
    }
    return this.adapter.speak(text, options);
  }

  stop(): void { this.adapter.stop(); }
  pause(): void { this.adapter.pause(); }
  resume(): void { this.adapter.resume(); }
  isSpeaking(): boolean { return this.adapter.isSpeaking(); }
  async getVoices() { return this.adapter.getVoices(); }
  isSupported(): boolean { return this.adapter.isSupported(); }

  private getDefaultRate(): number {
    // 从 user_profile 读取 current_level，映射到语速
    // 这里简化，实际应异步读取
    const rates: Record<string, number> = {
      'A1': 0.8, 'A2': 0.8, 'B1': 0.9, 'B2': 1.0, 'C1': 1.0, 'C2': 1.1
    };
    // 默认 B1
    return rates['B1'] ?? 0.9;
  }
}

export const ttsService = new TTSServiceWrapper();
```

```typescript
  requestPermission(): Promise<boolean>;
  start(): Promise<void>;
```

| 平台 | 录音实现 | 权限 API |
|------|---------|---------|
| Web / Electron | `navigator.mediaDevices.getUserMedia` + `MediaRecorder` | 浏览器弹窗 |
| iOS / Android | `expo-av` (Audio.Recording) | `Audio.requestPermissionsAsync()` |
| RN Windows | `react-native-audio-recorder-player` | Windows 能力声明 |
| RN macOS | `react-native-audio-recorder-player` | `NSMicrophoneUsageDescription` |

### Web 录音 Adapter

```typescript
// services/audio/WebAudioRecordAdapter.ts

export class WebAudioRecordAdapter implements IAudioRecordService {
  private mediaRecorder: MediaRecorder | null = null;
  private chunks: Blob[] = [];
  private stream: MediaStream | null = null;

  async requestPermission(): Promise<boolean> {
    try {
      this.stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      return true;
    } catch {
      return false;
    }
  }

  async start(): Promise<void> {
    if (!this.stream) {
      const ok = await this.requestPermission();
      if (!ok) throw new Error('Microphone permission denied');
    }
    this.chunks = [];
    this.mediaRecorder = new MediaRecorder(this.stream!);
    this.mediaRecorder.ondataavailable = (e) => this.chunks.push(e.data);
    this.mediaRecorder.start();
  }

  async stop(): Promise<{ uri: string; durationMs: number; sizeBytes: number }> {
    return new Promise((resolve) => {
      this.mediaRecorder!.onstop = () => {
        const blob = new Blob(this.chunks, { type: 'audio/webm' });
        const uri = URL.createObjectURL(blob);
        resolve({
          uri,
          durationMs: 0, // Web 端需另算
          sizeBytes: blob.size,
        });
      };
      this.mediaRecorder!.stop();
    });
  }

  async playback(uri: string): Promise<void> {
    const audio = new Audio(uri);
    await audio.play();
  }

  async delete(uri: string): Promise<void> {
    URL.revokeObjectURL(uri);
  }
}
```

### Native 录音 Adapter（expo-av）

```typescript
// services/audio/NativeAudioRecordAdapter.ts
import { Audio } from 'expo-av';

export class NativeAudioRecordAdapter implements IAudioRecordService {
  private recording: Audio.Recording | null = null;

  async requestPermission(): Promise<boolean> {
    const { status } = await Audio.requestPermissionsAsync();
    return status === 'granted';
  }

  async start(): Promise<void> {
    const ok = await this.requestPermission();
    if (!ok) throw new Error('Microphone permission denied');

    await Audio.setAudioModeAsync({
      allowsRecordingIOS: true,
      playsInSilentModeIOS: true,
    });

    this.recording = new Audio.Recording();
    await this.recording.prepareToRecordAsync(
      Audio.RecordingOptionsPresets.HIGH_QUALITY
    );
    await this.recording.startAsync();
  }

  async stop(): Promise<{ uri: string; durationMs: number; sizeBytes: number }> {
    if (!this.recording) throw new Error('No active recording');
    await this.recording.stopAndUnloadAsync();
    const uri = this.recording.getURI()!;
    const status = await this.recording.getStatusAsync();
    this.recording = null;
    return {
      uri,
      durationMs: status.durationMillis ?? 0,
      sizeBytes: status.fileSize ?? 0,
    };
  }

  async playback(uri: string): Promise<void> {
    const { sound } = await Audio.Sound.createAsync({ uri });
    await sound.playAsync();
    sound.setOnPlaybackStatusUpdate((s) => {
      if ('didJustFinish' in s && s.didJustFinish) sound.unloadAsync();
    });
  }

  async delete(uri: string): Promise<void> {
    // expo-file-system deleteAsync
```

## 九、语速分级策略（全局统一）

```typescript
// services/tts/speedConfig.ts

export function getTTSRate(userLevel: string, slow: boolean = false): number {
  const baseRates: Record<string, number> = {
    'A1': 0.8, 'A2': 0.8,
    'B1': 0.9,
    'B2': 1.0, 'C1': 1.0,
    'C2': 1.1
  };
  const base = baseRates[userLevel] ?? 0.9;
  return slow ? Math.max(0.5, base - 0.2) : base;
}

// 用户手动覆盖
export async function getEffectiveRate(userId: string, userLevel: string, slow: boolean): Promise<number> {
  const row = await StorageService.query<{ tts_rate_override: number | null }>(
    `SELECT tts_rate_override FROM user_profile WHERE user_id = ?`,
    [userId]
  );
  if (row[0]?.tts_rate_override) return row[0].tts_rate_override;
  return getTTSRate(userLevel, slow);
}
```

```typescript
// utils/platform.ts
import { Platform } from 'react-native';

export type AppPlatform = 'web' | 'ios' | 'android' | 'electron' | 'windows' | 'macos';

export function getAppPlatform(): AppPlatform {
  if (Platform.OS === 'web') {
    // 检测 Electron
    if (typeof window !== 'undefined' && 
        (window as any).process?.type === 'renderer') {
      return 'electron';
    }
    return 'web';
  }
  return Platform.OS as AppPlatform;
}

export function isWeb(): boolean {
  return getAppPlatform() === 'web' || getAppPlatform() === 'electron';
}

export function isNative(): boolean {
  return getAppPlatform() === 'ios' || getAppPlatform() === 'android';
}

export function isDesktop(): boolean {
  const p = getAppPlatform();
  return p === 'electron' || p === 'windows' || p === 'macos';
}
```

## 十三、补进 `.cursorrules` 的规则

```markdown
## 跨平台 TTS/录音规范

1. 所有 TTS 调用必须通过 `ttsService.speak()`，禁止直接调用 expo-speech / speechSynthesis
2. 所有录音调用必须通过 `audioRecordService.start()/stop()`，禁止直接调用 expo-av / MediaRecorder
3. 新 Adapter 必须实现 ITTSService / IAudioRecordService 接口
4. Platform.OS 判断只在 TTSServiceFactory 和 AudioRecordServiceFactory 中出现，业务层禁止 import Platform
5. Android 4000 字符限制由 NativeTTSAdapter 内部处理（自动分句），业务层无感知
6. Web 端首次 TTS 必须在用户手势事件中解锁（调用空 speak）
7. 语速由 getEffectiveRate() 统一计算：用户手动覆盖 > CEFR 等级默认值
8. 录音文件元数据必须写 speaking_recordings 表，含 platform 字段
9. 所有平台离线可用（系统 TTS 语音），不依赖网络
10. TTS 不可用时降级为"阅读模式"，不阻塞练习流程
```
